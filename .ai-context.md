# AI Context - GO2 Brain Logic & Autonomy Sub-repository

## Feladatkör
Ez az alrepó a robot magas szintű autonómiáját, logikáját, SLAM térképezését és küldetésvezérlését tartalmazza:
- `mission_control/`: Python alapú Mission Control backend (`core`, `mapping`, `navigation`, `orchestration`, `blackbox`, `fleet`, `audio`).
- `mapping/`: 2D/3D LiDAR SLAM térképezés és occupancy grid generálás.
- `mc_motion/`: Autonóm trajektória generálás, mozgástervezés és biztonsági védelmi zónák.

## ROS 2 / Autonómia Interfészek
- Nav2 Navigációs Akció: `/navigate_to_pose` (`nav2_msgs/action/NavigateToPose`)
- Térkép Topic: `/map` (`nav_msgs/msg/OccupancyGrid`)
- Robot Pozíció / TF: `/tf`, `/tf_static` (map -> odom -> base_link)
- Küldetés Események: MQTT / Internal Task Orchestration topics

## Önálló Autonómia Tesztelés
A logikai és térképező modulok tesztelése szintetikus belső bemenetekkel:
```bash
python mock_brain_inputs.py
```
